Nube de puntos de dron: qué es, cómo se genera y para qué sirve

Una nube de puntos puede contener millones de posiciones 3D, pero entender qué representa, cómo se obtiene y qué precisión puede ofrecer es esencial antes de utilizarla para mediciones, topografía, ingeniería o modelado.

¿Qué es una nube de puntos?

Una nube de puntos es una representación tridimensional formada por una gran cantidad de puntos con coordenadas X, Y y Z. Cada punto indica una posición en el espacio y, según el formato y el origen de los datos, puede almacenar además información como color RGB, intensidad, clasificación u otros atributos.

Vista desde lejos, una nube suficientemente densa puede parecer una superficie continua. Al acercarnos se aprecia que no está formada por caras ni superficies, sino por puntos independientes. Esta diferencia es importante: la nube describe la geometría observada, mientras que una malla conecta vértices mediante triángulos para crear una superficie.

Idea clave: una nube de puntos es, esencialmente, una colección de mediciones 3D. No es una fotografía y tampoco es todavía un modelo de superficies cerrado.

Cómo se genera una nube de puntos por fotogrametría

En fotogrametría no se mide cada punto con un láser. La geometría se estima comparando fotografías solapadas de la misma escena tomadas desde posiciones diferentes. El software identifica detalles comunes entre imágenes, calcula la posición de las cámaras y reconstruye profundidad.

1. Orientación de las fotografías

El primer paso consiste en relacionar unas fotografías con otras. Los puntos característicos comunes permiten calcular la geometría relativa del bloque y estimar la posición y orientación de las cámaras.

2. Información de profundidad

Una vez orientadas las cámaras, el software compara las imágenes y estima la profundidad de la escena. En Agisoft Metashape, utilizado por XProces como motor principal de fotogrametría, esta fase forma parte del proceso que permite reconstruir información 3D a partir de las imágenes orientadas.

3. Construcción de la nube

Los resultados de profundidad se combinan en una representación tridimensional. El número de puntos final depende del tamaño de la escena, resolución de las imágenes, calidad seleccionada, solape, textura de las superficies y otros factores.

No confundir densidad con precisión. Tener más puntos no garantiza automáticamente una geometría más exacta. Una nube puede ser muy densa y contener ruido, o ser menos densa y estar mejor ajustada geométricamente.

LAS, LAZ, PLY y otros formatos

Las nubes de puntos pueden intercambiarse en distintos formatos. La elección depende del programa de destino y de si se necesitan atributos adicionales.

Un archivo LAS no implica que la nube proceda de LiDAR. LAS es un formato de almacenamiento: puede contener una nube generada por escáner láser o por fotogrametría.

¿Para qué sirve una nube de puntos?

Medición 3D

Distancias, alturas, perfiles, dimensiones y comprobaciones geométricas cuando la escala y georreferenciación son adecuadas.

Topografía y terreno

Base para generar modelos de elevación, secciones, curvas de nivel y análisis de superficies.

Infraestructuras

Documentación de edificios, torres, taludes, obras, carreteras y otros activos visibles.

Comparación temporal

Contrastar campañas distintas para estudiar cambios, movimientos o evolución de una obra.

Modelado 3D

Puede utilizarse como base geométrica para reconstruir una malla o como referencia para modelado posterior.

Inspección visual

Cuando la nube conserva color, ayuda a contextualizar geometría y localizar elementos de la escena.

Qué determina la calidad de una nube fotogramétrica

  • Solape: cada zona debe aparecer desde suficientes posiciones distintas.
  • Nitidez: el movimiento, desenfoque o una velocidad de obturación inadecuada reducen detalles útiles.
  • Textura: superficies uniformes, transparentes o reflectantes son difíciles de correlacionar.
  • Geometría de captura: una escena 3D necesita puntos de vista adecuados, no solo muchas fotos desde casi la misma posición.
  • Resolución y distancia: determinan cuánto detalle puede observarse en las imágenes.
  • Georreferenciación: GPS, RTK/PPK o puntos de control influyen en cómo se sitúa y escala el resultado.
Para trabajar bien: evalúa primero el objetivo. Una nube destinada a documentación visual no exige exactamente lo mismo que una nube que se utilizará para mediciones topográficas.

Preguntas frecuentes

¿Una nube de puntos fotogramétrica es igual que una nube LiDAR?

No. El aspecto final puede ser parecido, pero el método de adquisición es distinto. El LiDAR mide distancias mediante pulsos láser; la fotogrametría reconstruye geometría comparando imágenes desde distintos puntos de vista.

¿Se puede medir directamente sobre una nube de puntos?

Sí, siempre que la nube tenga escala y referencia adecuadas y que la precisión del proyecto sea suficiente para la medición que se pretende realizar.

¿Qué es mejor, LAS o LAZ?

Depende del flujo de trabajo. LAZ reduce considerablemente el tamaño, pero el software de destino debe admitirlo. LAS sigue siendo un formato muy extendido.

¿Cuantos más puntos tenga la nube, mejor?

No necesariamente. La densidad es solo una característica. La calidad geométrica, ruido, cobertura y precisión son igual o más importantes.
