Precio de fotogrametría: de qué depende el coste de procesar un vuelo

El precio de un proyecto no depende solo de contar fotografías. Resolución, calidad, tipo de producto y complejidad del flujo determinan cuántos recursos necesita el procesamiento.

Por qué un procesamiento fotogramétrico no tiene siempre el mismo coste

El coste no depende únicamente del número de fotografías. Procesar fotogrametría consume almacenamiento, transferencia, CPU/GPU, memoria y tiempo de ejecución, y cada producto solicitado añade etapas o exportaciones.

Dos proyectos con 300 fotografías pueden ser muy diferentes: uno puede contener imágenes pequeñas de una parcela sencilla y otro imágenes de alta resolución para una reconstrucción 3D compleja.

En XProces el objetivo es que puedas conocer una estimación antes de registrarte y antes de confirmar el trabajo. Seleccionas las fotografías, la plataforma analiza el dataset y muestra tiempo y precio en función de la configuración disponible.

Factores que influyen en el precio

Número de imágenes

Más fotografías implican más comparaciones, lectura de datos y almacenamiento.

Resolución

Imágenes mayores contienen más píxeles y requieren más memoria y cálculo.

Calidad seleccionada

Los niveles de procesamiento pueden cambiar la resolución interna de determinadas etapas y, con ello, el tiempo.

Productos finales

Ortofoto, DSM, DTM, nube, malla o diferentes exportaciones requieren etapas distintas.

Tipo de proyecto

Una cartografía nadiral y un modelo 3D complejo no tienen exactamente el mismo flujo.

Procesado supervisado

Casos especiales pueden requerir revisión humana, parámetros específicos o delimitación personalizada.

Calidad: qué estás pagando realmente

En fotogrametría, “máxima calidad” suele significar que determinadas etapas trabajan con más información de las imágenes y producen resultados más densos o detallados. Eso aumenta de forma importante el coste computacional.

Elegir siempre el nivel máximo no es necesariamente la mejor decisión. Si el producto final es una ortofoto para visualización general, una configuración intermedia puede ser suficiente. Si se busca máximo detalle para inspección o un modelo 3D complejo, puede justificar más recursos.

Calidad de procesamiento no corrige una captura mala. Aumentar recursos no puede recuperar superficies que nunca se fotografiaron, eliminar movimiento de cámara ni crear solape inexistente.

Tiempo estimado y tiempo real

La estimación previa ayuda a decidir, pero el tiempo real puede variar. La complejidad de las imágenes no siempre se conoce hasta que comienza la reconstrucción.

Algunos factores que pueden alargar el trabajo son:

  • mucha resolución por fotografía;
  • gran número de imágenes;
  • escenas con vegetación o geometría compleja;
  • alta calidad seleccionada;
  • mallas o texturas muy pesadas;
  • exportaciones de gran tamaño.

XProces muestra el progreso del proyecto para que el usuario pueda seguir la fase actual y los resultados cuando finalizan.

Cómo comparar precios entre servicios de fotogrametría

Un precio bajo no significa lo mismo si los entregables, calidad o límites son distintos. Antes de comparar conviene revisar:

  • qué productos están incluidos;
  • qué formatos se entregan;
  • si hay límites por número de fotos o tamaño;
  • qué nivel de calidad se utiliza;
  • si el precio incluye almacenamiento o descarga;
  • si existe soporte cuando un dataset presenta incidencias;
  • si el procesamiento es automático o incluye supervisión.

Preguntas frecuentes

¿El precio depende solo del número de fotografías?

No. También influyen resolución, calidad seleccionada, tipo de procesamiento y productos solicitados.

¿Puedo conocer el precio antes de registrarme?

Sí. El flujo actual de XProces permite seleccionar las fotografías y obtener análisis, tiempo y precio antes de solicitar el registro para iniciar el trabajo.

¿Máxima calidad siempre produce el mejor resultado?

No si el dataset tiene problemas de captura. Una configuración más exigente no puede sustituir solape, enfoque o cobertura que no existen.

¿Una ortofoto y un modelo 3D cuestan lo mismo?

No necesariamente. Sus flujos y necesidades de cálculo son diferentes, y el coste depende también del resto de productos y de la configuración.

¿Un procesamiento especial puede requerir presupuesto personalizado?

Sí. Proyectos con requisitos específicos, delimitaciones, formatos especiales o supervisión técnica pueden necesitar un flujo a medida.
